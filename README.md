# «КЕНГУРУ» математикалық ойын-конкурсы — дайын сайт

Бұл пакетте толық жұмыс істейтін FastAPI сайты бар.

## Дайын функциялар
- 1–11 сынып және қазақша/орысша интерфейс.
- Қатысу құны: 1000 ₸.
- 30 сұрақ, 30 минут, бір мүмкіндік.
- Kaspi QR және төлем сілтемесі.
- Төлемді ұйымдастырушы панелінен қолмен растау.
- Автоматты тексеру.
- 26–30: I орын; 21–25: II орын; 16–20: III орын; 0–15: сертификат.
- Атаулы диплом және бірегей нөмір.
- Қатысушы қайта кірсе, өтінім браузерде сақталады.
- Таймер сервер жағында да тексеріледі.
- SQLite дерекқоры.

## Windows-та іске қосу
1. Python 3.11+ орнатыңыз.
2. Осы папканы ашып PowerShell іске қосыңыз.
3. Орындаңыз:

```powershell
pip install -r requirements.txt
$env:KENGURU_ADMIN_PASSWORD="ӨЗІҢІЗДІҢ_КҮРДЕЛІ_ПАРОЛІҢІЗ"
uvicorn main:app --host 0.0.0.0 --port 8000
```

Сайт: http://127.0.0.1:8000
Admin: http://127.0.0.1:8000/admin

## Интернетке шығару
VPS/Render/Railway секілді Python hosting-ке файлдарды жүктеп, start command ретінде:

`uvicorn main:app --host 0.0.0.0 --port $PORT`

Environment variable:
`KENGURU_ADMIN_PASSWORD=күрделі-пароль`

## Төлем
Қазіргі нұсқада Kaspi төлемін ұйымдастырушы өзі растайды. Банк/эквайринг API берілген жағдайда webhook арқылы автоматты растауды қосуға болады.

## Сұрақтар туралы
Сұрақ банкі — сайттың жұмысын іске қосуға арналған түпнұсқа генерацияланған тапсырмалар. Пайдаланушы берген 1–2 сынып PDF үлгісі тек формат/күрделілік құрылымына бағдар ретінде пайдаланылды; ондағы тапсырмалар сөзбе-сөз көшірілмеді.
